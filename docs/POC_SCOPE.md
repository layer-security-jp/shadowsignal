# ShadowSignal 限定PoC

## 目的

管理対象端末で、暗号化通信の本文を扱わずに生成AI利用の兆候を判定できるか確認します。
APIの形状判定と、端末内に保持した宛先・プロセス情報を分離して評価します。

## 実施内容

- Windows 10/11またはmacOS 13以降の管理対象端末で実施
- 対象ホストを指定し、1回45秒を目安に計測
- APIへ送信するJSONを送信前に画面で確認
- 生成操作と非生成操作を分けて複数回測定
- 3値の形状判定、信頼度、ローカルで結合した最終判定を記録

## 必要なもの

- Python 3.11以降
- パケット取得を実行できる管理者権限
- Layer Securityが別経路で発行するPoC用APIキー
- 利用許可を得た端末、ネットワーク、生成AIアカウント

## 確認項目

1. API送信データに宛先、IP、プロセス、生パケット、通信本文が含まれないこと
2. 対象の生成操作で通信形状を取得し、判定結果を返せること
3. 一般Web、ダウンロード、継続ストリーム等を対照測定できること
4. 同じ観測IDでAPI結果と端末内情報を結合できること
5. 誤検知、見逃し、判定保留を分けて記録できること

## PoCに含まれないもの

- 全生成AIサービス・全IDEに対する検知保証
- 常駐エージェントによる全社継続監視
- 通信の自動遮断やDLPポリシーの強制
- 本番SLA、24時間監視、顧客環境向けの個別運用設計

本番導入では、対象シナリオごとの実測結果を基に、既存DLP・SSE・SIEMとの接続方式と
判定保留時の運用を個別に設計します。
